# Sample KYC Document Data

This directory contains sample data for the KYC document retrieval pipeline. To use this pipeline, you should place your own sample documents in the appropriate subfolders:

- **DrivingLicenses/**: Place driver's license and ID card images here (JPG/JPEG format)
- **W2Sample/**: Place W2 tax form documents here (PDF format)
- **Form1040Sample/**: Place Form 1040 tax return documents here (PDF format)
- **Utility/**: Place utility bill documents here (PDF format)
- **Realistic_Bank_Statements.pdf**: Place bank statement PDFs in the root data folder

## Document Naming Conventions

For best results with person-specific searches, name your documents to reflect the person they belong to:

- `AprilHensleyForm1040.pdf`
- `JWDL.jpeg` (James Williams Driver's License)
- `Taylorcoxutility.pdf`

## Privacy Notice

This sample data is for demonstration purposes only. Do not upload real KYC documents with sensitive personal information to public repositories.
