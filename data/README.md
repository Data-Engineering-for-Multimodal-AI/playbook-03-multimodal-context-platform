## Source and license

All files here were generated by
[`scripts/generate_sample_data.py`](../scripts/generate_sample_data.py) for
this repository and are released under the MIT License, like the code. To
recreate them, run this command; the output is identical on every run:

```bash
uv run --group dev python scripts/generate_sample_data.py
```

The documents used in the first edition were never committed to the
repository, and their source isn't recorded. These replacements are new. They
keep the customer names and file names that the book's example output shows,
but the contents and scores differ.

## These are not real documents

- Every person, employer, utility, bank, address, account number and license
  number is invented. Any resemblance to a real person or business is
  coincidental.
- Social Security numbers are in the 987-65-4320 to 987-65-4329 block that the
  Social Security Administration reserves for advertising. Employer EINs start
  with `00`, a prefix the IRS never assigns. Phone numbers use the fictional
  555-01xx range.
- Every page and card is marked SPECIMEN and carries a "not a real document"
  notice. The license cards have a silhouette in place of a photo, and no seal,
  barcode or security features.

The figures in the documents are consistent with each other. W-2 wages and
withholding carry over to the Form 1040, which uses the 2024 tax table and
standard deduction. Each bank statement shows the customer's biweekly net pay
from the W-2 employer and the utility bill payment. The state tax figures
are simplified.

Don't put real KYC documents in a public repository.
