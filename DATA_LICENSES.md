# Data licenses

This file lists the datasets and models this playbook uses, where they come from, and their licenses. The code in this repository is MIT-licensed. That license does not cover third-party data or models; each one keeps its own license, listed below.

## Datasets

| Dataset | Source | License | In this repo |
|---|---|---|---|
| KYC documents (22 documents for five fictional customers: driver's license cards, W-2s, Form 1040s, utility bills and a bank statement; each marked SPECIMEN), and the text printed on each card | Synthetic, generated by `scripts/generate_sample_data.py` | MIT (this repository) | `data/` (768 KB), including `data/extracted_text/`. `make data` regenerates the same files |

## Models

| Model | Source | License | How it's used |
|---|---|---|---|
| all-MiniLM-L6-v2 | [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) | Apache-2.0 | Embeds the documents in local mode (`--local`, which `make run` uses). Downloaded from Hugging Face on first use. Set by `LOCAL_EMBEDDING_MODEL` in `src/kyc.py` |
| Vertex AI `text-embedding-005` | Google Vertex AI, hosted | Hosted service; no weights are downloaded. Use is governed by Google Cloud's terms | Embeds the documents in cloud mode. Set by `EMBEDDING_MODEL` |
| Document AI processors (OCR, US Driver License Parser) | Google Cloud Document AI, hosted | Hosted service; use is governed by Google Cloud's terms | Extracts text and entities in cloud mode (`src/document_processor.py`). Local mode reads `data/extracted_text/` instead |
